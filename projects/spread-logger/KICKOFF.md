# spread-logger キックオフ

## 目的
国内取引所×Hyperliquidの価格・ファンディングの歪みを24時間観測し、「いつ・どこで・何bpsの歪みが・どれくらい続くか」の統計を自分だけが持つ状態を作る。
直近の狙いは2つ: (1) 合成ドル円仮説(土日の実効ドル円が金曜終値から乖離する)の定量検証データを貯める、(2) 閾値を超える歪みが出た瞬間にDiscordで知る。

## 仕様
- **入力**(すべて公開API、認証不要):
  - 国内: bitFlyer / bitbank / GMOコイン / Coincheck のティッカー(best bid/ask) — BTC/JPY, ETH/JPY, XRP/JPY, SOL/JPY, DOGE/JPY, LTC/JPY(各取引所で取扱いのあるペアのみ。未上場はスキップ)
  - Hyperliquid: info API — パープのmid・ファンディングレート、現物ミッド(HYPE/UBTC/UETH/USOL)
  - USDJPY参照レート: 無料FX API(平日は実勢、週末は金曜終値として扱う)
- **出力**:
  - `data/YYYY-MM.csv` に15分毎1行追記(タイムスタンプ、各所価格、HLのmid/FR、計算済み乖離指標)
  - 計算する乖離指標:
    1. **実効ドル円** = 国内BTC/JPY ÷ HL BTCパープUSD、およびその金曜終値(参照レート)からの乖離%
    2. **国内取引所間乖離**(同一銘柄のbest bid/ask クロス)
    3. **HL現物−パープのベーシス**(HYPE/UBTC/UETH/USOL)
    4. **FR年率換算**(HL全対象銘柄)
  - Discordアラート(既存Webhook流用): 閾値超え時のみ。同一条件はクールダウン(暫定6時間)で連投防止
- **使う場面**: GitHub Actionsで15分毎に無人実行。ユーザーは通知を受け取る+数週間後にCSVで分布を分析
- **やらないこと**: 自動発注 / 海外CEX / 板の深さ(depth)取得 / バックテスト / 週次サマリー通知(データが貯まったら後続候補)

## 完成の定義
### ツールの正しさ(作った直後に検証)
- [ ] 各取引所の価格が手動確認(取引所の画面)と一致する
- [ ] 実効ドル円・乖離%・FR年率の計算が手計算と一致する
- [ ] 閾値を意図的に下げるとテストアラートがDiscordに届く
- [ ] 取得失敗(1取引所ダウン等)でも落ちずに残りを記録し、エラーが通知される
- [ ] Actionsが15分毎に走りCSVが伸びていく(数日運用で確認)
### 成果(運用して評価)
- 土日の実効ドル円乖離の分布が取れ、合成ドル円戦略のGO/NO-GO判断ができる
- アラート起点で実際に取れた歪みが月1回以上ある(数ヶ月スパンで評価)

## マイルストーン
1. データ取得層(4国内所+HL+FXレート)+CSV1行出力 → 確認方法: ローカル1回実行し、値を取引所画面と突合
2. 乖離計算(実効ドル円・国内間・ベーシス・FR年率) → 確認方法: 手計算と照合
3. Discordアラート(閾値+クールダウン+エラー通知) → 確認方法: 閾値を下げてテスト通知が届く
4. GitHub Actionsワークフロー(15分cron、CSVコミット) → 確認方法: 2〜3日放置してCSVの欠測率と通知を確認
